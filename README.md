# VEYRA 💗

> Meet someone who remembers.

VEYRA is an AI-powered social and communication experience designed around meaningful conversations, roleplay, stories, and personalized interactions.

Instead of feeling like a traditional chatbot, VEYRA focuses on creating conversations that feel more natural, personal, and engaging.

---

## ✨ Features

- 💬 AI-powered conversational experience
- 🎭 Story-based character interactions
- 🧠 Personalized conversations
- 🌐 English, Hindi & Hinglish support
- 😊 Emoji picker
- ⏱️ Message timestamps
- ✓✓ Read indicators
- ⌨️ Typing indicator
- 💾 Local chat history using LocalStorage
- 📱 Responsive design
- 🎨 Premium dark-themed UI
- 🖼️ Character avatars and story visuals
- ⚡ Interactive chat experience

---

## 🎭 Stories

VEYRA currently includes multiple interactive story experiences:

- **The Girl in Seat 27**
- **3:17 AM**
- **My Fake Girlfriend**
- **The Rival Next Door**
- **She Remembers Everything**
- **One Summer, One Secret**

Each story has its own character, conversation context, avatar and visual theme.
